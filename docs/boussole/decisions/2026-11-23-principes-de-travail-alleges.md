# Adopter des principes de travail allégés

- **Date :** 2026-11-23
- **Statut :** Acceptée (confirmée par Marc le 2026-11-23)
- **Source :** Demande de Marc, 23 nov. 2026 ; `docs/boussole/PRINCIPES.md`.

## Contexte
Les règles d'`AGENTS.md` disent comment saisir et publier, mais pas comment trancher quand aucune règle ne s'applique. Un collaborateur humain ou un agent a besoin de repères de travail écrits, proportionnés à un petit site statique.

## Options
- A. Aucun principe écrit.
- B. Un cadre d'ingénierie complet (portes de qualité, rôles, fusion sur approbation).
- C. Une courte liste de principes, adaptée à un petit site statique sans pull request.

## Pour et contre
- A : rien à maintenir, mais un agent n'a rien pour trancher.
- B : rigoureux, mais disproportionné pour un projet d'une personne.
- C : garde la simplicité, une seule source par concept, l'honnêteté et la place de Marc dans les décisions.

## Décision
Option C : treize principes courts dans `PRINCIPES.md`, chacun avec un exemple du projet. Marc décide des changements de direction ; les saisies et les correctifs vont directement sur `main`.

## Conséquences
- `AGENTS.md` reste une table de pointeurs ; la boussole ne duplique rien.
- Les principes seront revus à la fin de la saison 2026-27.
