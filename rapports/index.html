Sur les 102 jours mesurés, 649 bûches ont évité ≈ 2 921 kWh, ou 337 $ ; projeté sur toute la saison (≈ 928 bûches), le bois rapporte ≈ 482 $ pour 425 $ payés : gain modeste. Ce que disent les données

kWh réels selon la température

Les jours sans feu (gris) sont presque tous des jours doux : on n'a jamais observé un jour très froid sans feu. C'est pourquoi le modèle utilise tous les jours, avec la température et le nombre de bûches ensemble, plutôt que les seuls jours sans feu.

Ton heuristique vs le modèle

Chaque point = un jour. L'écart « eq − réel » de ton chiffrier suit le nombre de bûches avec une pente proche de 4,5 kWh par bûche.
